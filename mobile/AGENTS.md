# Expo HAS CHANGED

This app targets **Expo SDK 54** (`expo@54.x`, React Native 0.81, React 19).
Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before
writing any code.

Do not follow docs for a newer SDK — the APIs differ. Version pins are governed by
`node_modules/expo/bundledNativeModules.json`; check a package against it before
changing a pin, and prefer `npx expo install <pkg>` over `npm install` so the
SDK-compatible version is chosen.

(This file previously pointed at v57.0.0, which was never the installed SDK — see
Q5 in DECISIONS-FOR-AVI.md.)
